Firebase Realtime Database Security Rules
===========================================

Copy these rules to your Firebase Console:
https://console.firebase.google.com → daily-chores-b0e54 → Realtime Database → Rules

{
  "rules": {
    "users": {
      ".read": true,
      ".write": true,
      "$uid": {
        ".read": true,
        ".write": true
      }
    },
    "admins": {
      ".read": true,
      ".write": true,
      "$adminId": {
        ".read": true,
        ".write": true
      }
    },
    "tasks": {
      ".read": true,
      ".write": true,
      "$taskId": {
        ".read": true,
        ".write": true
      }
    },
    "assignments": {
      ".read": true,
      ".write": true,
      "$uid": {
        ".read": true,
        ".write": true,
        "$taskId": {
          ".read": true,
          ".write": true
        }
      }
    },
    "completions": {
      ".read": true,
      ".write": true,
      "$date": {
        ".read": true,
        ".write": true,
        "$uid": {
          ".read": true,
          ".write": true,
          "$taskId": {
            ".read": true,
            ".write": true
          }
        }
      }
    },
    "dailyEarnings": {
      ".read": true,
      ".write": true,
      "$date": {
        ".read": true,
        ".write": true,
        "$uid": {
          ".read": true,
          ".write": true

    },
    "monthlyEarnings": {
      ".read": true,
      ".write": true,
      "$month": {
        ".read": true,
        ".write": true,
        "$uid": {
          ".read": true,
          ".write": true
        }
      }
    }
  }
}

Steps:
1. Open Firebase Console → daily-chores-b0e54
2. Go to Realtime Database → Rules tab
3. Replace ALL content with the rules above
4. Click "Publish"
5. Refresh your browser and try again

NOTE: These are test/development rules with no authentication.
For production, restrict read/write based on user authentication.
